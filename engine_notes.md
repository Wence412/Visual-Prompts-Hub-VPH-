# Prompt-writing notes

Start with a clear subject and describe what must remain visible. Name the material, surface finish, light direction, viewpoint, and available space for copy. Use APAE as a brief, then turn it into readable instructions.

## Product and editorial images

- Specify the position of each object and the camera angle.
- Describe highlights and shadows in physical terms. “Soft window light from camera left” is more useful than a string of quality adjectives.
- Treat lens and aperture language as visual direction. Inspect the result for perspective and depth of field.
- For materials, ask for visible grain, weave, reflection, or edge detail where it matters.

## References and continuity

Supply authorized references when the subject or product must remain recognizable. State which details should stay fixed and which may change. For a series, compare each output with the same reference and brief.

## Exclusions and variants

Include relevant exclusions in the prompt when the tool has no separate negative field. Remove “text” or “logos” from exclusions when authorized lettering or branding is required. Negative lists are review aids, not enforcement controls.

Change one variable when testing an effect. The existing variants sometimes change several elements and should be treated as separate art directions rather than controlled comparisons.

See [engine_comparison.md](engine_comparison.md) for execution boundaries. Do not use “4K,” “8K,” or a quality adjective as evidence of output size or quality.
